# vexa-mcp source

- `main.rs`: the boot (environment, surface, assembly, late domains, listener).
- `server.rs`, `wire.rs`: the HTTP server, the request and answer types.
- `edge.rs`: the route table, the request pipeline of each tool route, the gateway hop and the assembled-tool forward.
- `mcp.rs`: the MCP transport (sessions, SSE), JSON-RPC, `tools/call`, notices, error rendering and tool visibility.
- `builtin.rs`: the 18 built-in tools.
- `assembly.rs`: manifest validation, discovery, binding to each domain's OpenAPI, and the late domains.
- `pyd.rs`, `schema.rs`: pydantic (lax mode) and jsonschema validation with the Python error text.
- `pyjson_decode.rs`: `json.loads` with the CPython error text.
- `link.rs`, `tickets.rs`: meeting-link parsing and `report_issue` tickets.
- `net.rs`, `obs.rs`: the outbound HTTP client, trace ids and log lines.
- `surface.json`: generated by `../gen_surface.py`.
